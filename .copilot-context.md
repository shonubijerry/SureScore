# SureScore compact context

Repo: pnpm monorepo. apps/api = Cloudflare Worker + Hono + Chanfana; apps/ui = Vite + React; packages/db = Prisma + D1; packages/shared = config + domain rules.

Product rules: Nigeria launch; no cross-currency payouts; settlement uses 90 min regulation only; extra time/penalties excluded; prediction lock 15 min before kickoff; cancellation allowed until 20 min before kickoff; postponed/abandoned matches trigger refund initiation; platform fee 10%; winner pool 90%; 3-winner default split 50/30/20; ties merge slots equally.

Architecture: provider logic isolated from core domain; country/provider config is static and config-driven; sessions use JWT + KV; durable relational data stays in D1; use resource-based route modules with one endpoint per file; Chanfana OpenAPIRoute classes + Zod schemas; financial flows must be idempotent and auditable.

Key files: [CONTEXT.md](CONTEXT.md), [apps/api/CONTEXT.md](apps/api/CONTEXT.md), [apps/api/src/routes/CONTEXT.md](apps/api/src/routes/CONTEXT.md), [apps/ui/CONTEXT.md](apps/ui/CONTEXT.md), [packages/db/CONTEXT.md](packages/db/CONTEXT.md), [packages/shared/CONTEXT.md](packages/shared/CONTEXT.md).

Implemented: signup/login, country-aware auth, payout account CRUD, country/provider config endpoints, first-prediction payout gate, KV session validation.

Caveats: local Prisma + Wrangler/Vitest runtime has a known incompatibility; build and dry-run validation are the preferred verification path when DB runtime issues appear locally.
